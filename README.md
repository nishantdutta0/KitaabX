# KitaabX

A student-focused web portal for sharing and accessing handwritten academic notes and previous-year question papers.

## Overview

KitaabX was developed by a team of three after we experienced how difficult it could be to find useful study material before college exams. The platform lets students create accounts, access available resources, and contribute notes and previous-year papers for other students.

## Features

- Student account creation and authentication
- Access to shared handwritten notes
- Support for contributing notes and previous-year question papers
- A web interface built for sharing academic resources

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** Node.js, Express.js
- **Database:** MongoDB

## What I Learned

This project provided practical experience with full-stack web development, building REST-oriented backend functionality, connecting a web application to a database, and collaborating on a team project.
